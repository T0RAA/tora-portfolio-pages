The starting point

Bring branching, merging, and rollback to digital audio workstation files so creative versions can be managed deliberately.

What I contributed

Designed a Git-inspired version-control system and built a full-stack Electron application supporting Ableton Live, Logic Pro X, and FL Studio.

How it works

An Electron desktop client uses React and TypeScript, backed by FastAPI and Supabase. Clerk supports authentication and Sentry supports application monitoring.

What came out of it

  • Implemented branching, merging, and rollback for DAW files.
  • Adopted by a UCSC music production course.
  • Supported Ableton Live, Logic Pro X, and FL Studio.

The bigger possibility

Give creators confidence to try new directions and collaborate while preserving the work that came before. Course adoption is documented; wider adoption is not claimed.
