The starting point

Build a campus event discovery platform for the UCSC community.

What I contributed

Led product as Product Owner for a five-person team. Shipped the home feed, event creation, and profile editing using Scrum-based agile development.

How it works

Connected Google OAuth to a Supabase profile system and a Python event-scraping pipeline, with a React interface for discovery and participation.

What came out of it

  • Led product for a five-person team.
  • Shipped the home feed, event creation, and profile editing.
  • Integrated Google OAuth, profiles, and an event-scraping pipeline.

The bigger possibility

Make it easier for students to discover opportunities and participate in campus life. Attendance and engagement improvements have not been measured in the supplied resume.
