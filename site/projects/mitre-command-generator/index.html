The starting point

Ground adversarial command generation in the MITRE ATT&CK framework and reduce hallucinated commands.

What I contributed

Built a multi-agent AI pipeline for MITRE ATT&CK-aligned command generation and fine-tuned Llama 3.1 and Qwen using HuggingFace Transformers.

How it works

A retrieval-augmented generation pipeline grounds model output in framework material. Fine-tuned models and multiple agents support command generation across tactic and technique categories.

What came out of it

  • Covered 193+ ATT&CK techniques across 14 tactic categories.
  • Combined fine-tuning with retrieval grounding.
  • Reduced hallucinated commands; the resume does not provide a measured reduction rate.

The bigger possibility

Make AI-assisted security research more grounded and dependable. This showcase describes the research and system design rather than providing executable attack instructions.
